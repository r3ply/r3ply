# r3ply docs

`/docs/content` contains the documentation as a [zola](https://getzola.org/) site, with tailwind 4.1.x for styling.

## Install/Build/Run

`npm install` to build dependencies
`npm run build` to build statically once (use `BUILD_OPTS` to specify build options)
`npm run serve` to build in memory, and serve at `127.0.0.1:1111` by default. (use `SERVE_OPTS` for serve options)
