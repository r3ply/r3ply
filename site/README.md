# r3ply site and docs

`/docs/content` contains the documentation as a [zola](https://getzola.org/) site, with tailwind 4.1.x for styling.

## Install/Build/Run

`pnpm install` to build dependencies
`pnpm build` to build statically once (use `BUILD_OPTS` to specify build options)
`pnpm serve` to build in memory, and serve at `127.0.0.1:1111` by default. (use `SERVE_OPTS` for serve options)
