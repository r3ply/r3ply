## Roadmap

### Config

- [x] `site`, `comments`, `moderation` top-level variables
- [ ] Secret storage Allow users to store encrypted secrets in their config, e.g. protect webhook endpoint
- [ ] `notify` top-level variables - allow notification channels to be added and configured, e.g. slack message or email
- [ ] Stabilize config API for existing features
